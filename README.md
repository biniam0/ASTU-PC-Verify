# ASTU-PC-Verify

ASTU-PC-Verify is a web-based system for preventing unauthorized removal of student laptops from campus.

## Workspace Structure

- `backend/`: TypeScript Express backend implementing authentication, student registration, laptop registration, verification, alerts, scan logs, and admin reporting.
- `frontend/`: Frontend workspace placeholder.

## Backend Status

The backend has been scaffolded and is runnable.

From `backend/`:

```bash
npm install
npm run dev
```

See `backend/README.md` for API details and the seeded administrator credentials.
